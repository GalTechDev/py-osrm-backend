D'un fichier de carte brut à un itinéraire servi en HTTP.

Parsing OSM

map

Lisez des extraits OpenStreetMap en XML (en flux avec iterparse) ou en PBF (via osmium) pour en extraire les nœuds et les voies.

.osm .osm.pbf

Construction du graphe

hub

Conserve chaque voie highway, pondère chaque segment par la distance haversine et respecte oneway=yes.

GraphBuilder haversine

Dijkstra

directions

Plus court chemin exact avec une file de priorité en tas binaire et arrêt anticipé dès que la destination est atteinte.

heapq O(E log V)

Contraction Hierarchies

bolt

La technique au cœur d'OSRM : contraction des nœuds par importance, ajout de raccourcis, puis réponse par une recherche bidirectionnelle ascendante.

preprocess() query()

flask geojson

DÉMARRAGE RAPIDE

  • play_arrow Téléchargez un extrait (par exemple sur Geofabrik) et passez-le à GraphBuilder. Le format est détecté d'après l'extension.
  • play_arrow Créez un DijkstraEngine sur le graphe, ou pré-traitez un ContractionHierarchies.
  • play_arrow Interrogez deux identifiants de nœuds OSM : vous obtenez la distance en kilomètres et la liste des nœuds du trajet.
RÉFÉRENCE API COMPLÈTE arrow_forward

code quickstart.py 

from osrm import GraphBuilder, DijkstraEngine

# Parse la carte et construit le graphe routable
graph = GraphBuilder().build_graph("monaco.osm.pbf")

# Moteur de routage
engine = DijkstraEngine(graph)

# Deux identifiants de nœuds OSM
distance, path = engine.shortest_path(start_id, end_id)

print(f"{distance:.2f} km via {len(path)} nœuds")
for node_id in path:
    node = graph.get_node(node_id)
    print(node.lat, node.lon)

PIPELINE

Chaque étape est un module à part : remplacez le parser, les poids ou l'algorithme sans toucher au reste.

01 · INPUT
OSM

Extrait .osm XML ou .osm.pbf.

02 · EXTRACTOR
GraphBuilder

Parse nœuds et voies, construit les arêtes pondérées.

03 · ENGINE
Dijkstra · CH

Calcule le plus court chemin entre deux nœuds.

04 · SERVER
Flask API

Accroche les coordonnées au graphe, renvoie du GeoJSON.
